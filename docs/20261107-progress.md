# Temple 작업 저장 — 2026-11-07

## 현재 구현
- 본당·기도실·고해성사실, 크리스마스 장식, 목사와 성가대, HDRI 조명, 눈, 배경음악, 예배영상.
- 의자 근처에서 앉기 버튼 또는 E키로 앉기/일어나기. 확대된 공간에 맞춘 감지 범위와 빈 좌석 선택.
- 자동 방문객 30명. 처음 18명은 착석하고 12명은 통로에서 시작하며 걷기·앉기·일어나기를 반복.
- 헌금 왼쪽의 소원 버튼. 소원 내용을 표면에 적은 둥근 3D 하트 풍선이 캐릭터 위에서 천천히 상승하며 약 40초 후 사라짐.
- 자동 방문객도 번갈아 약 12초 간격으로 소원 풍선을 띄움. 서버에서 모든 접속자에게 공유하고 새 입장자에게 현재 떠 있는 풍선 상태를 전달.
- 소원은 최대 200자, 10초에 3개. 화면의 동시 풍선은 최대 16개. 내용은 영구 보관하지 않음.
- 휴대폰 가로·세로 자동 맞춤, 가로 모드 버튼·입력창 조정, 회전 중 접속과 캐릭터 위치 유지. 홈 화면 앱의 orientation은 any.
- 두 손가락 확대·축소, 모바일 키보드 대응.

## 사용 방법
- 이동: 바닥 클릭/터치 또는 WASD/방향키.
- 앉기/일어나기: 가까운 빈 의자에서 앉기 버튼 또는 E.
- 소원: 소원 버튼 → 내용 입력 → 하트 풍선 띄우기.
- 휴대폰 회전: 자동 회전 켜기 / 아이폰 회전 잠금 해제.
- VS Code 중앙 미리보기: 주소창 왼쪽 Reload, Ctrl+R. 이전 자산이 남으면 Ctrl+Shift+R.

## 실행과 복원
- Node.js 22.12 이상. npm ci, npm ci --prefix server, npm run build.
- 월드 서버: npm run world. 기본 포트 8790.
- 기존 Windows 실행기: start-temple.ps1. 모바일 게이트웨이 포트 8810. Cloudflare 터널 도구와 설정은 로컬 환경에 별도 보관.
- 실제 음악 파일은 로컬 전체 백업 ZIP에 보관. ZIP의 Temple/public/music 및 Temple/MP3를 복원하면 기존 음원을 그대로 재생할 수 있음.
- 특히 christmas-choir-carols.mp3는 166,375,895바이트로 일반 GitHub 파일 한도를 초과하므로 GitHub 소스 백업에서 제외.
- 환경 파일, 실행 중 로그·임시 터널 주소, 캐시와 node_modules는 GitHub 백업에서 제외.
