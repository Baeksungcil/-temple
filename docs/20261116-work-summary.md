# 복음교회 프로젝트 저장 기록 — 2026-11-16

## 기능 변경

- 안수기도: 의자와 방문객을 피해 다가오기, 서 있거나 앉은 플레이어 정면에 서기, 정상 비율의 신부님과 손잡기, 몸 회전 최대 20도, 머리·몸통 겹침 방지.
- 안수기도 중 20초 동안 기도문과 남은 시간 표시. 두 사람이 보이는 옆 시점으로 전환하고 종료 시 원래 시점 복원.
- 앉기: 가까운 빈자리로 경로 이동 후 앉기. 서버에서 도착 위치가 확인된 후 좌석 요청. 바닥 클릭 시 자동으로 일어나 클릭 지점으로 이동.
- 찬송가: `MP3/Hymn`의 10개 MIDI를 오르간 음색 WAV로 변환. 무작위 순서로 연속 재생하며 한 순환 내 중복과 순환 경계의 연속 중복 방지.
- 메뉴: 좌우 화살표, 화면 폭에 맞는 정수 개 버튼 표시, 버튼·빈 공간 드래그, 드래그 종료 시 버튼 경계 정렬, 잘못된 버튼 클릭 방지, 흰 스크롤바 숨김.
- 왼쪽 최근 대화 표시 15초에서 45초로 연장.
- 복음교회: 상단 명판과 본당의 녹색·금장 간판, 십자가 문장, 고해상도 한글 및 영문 표기.
- 크리스마스 트리: 모든 배치·크기를 공유 데이터로 관리하여 화면, 클라이언트 경로 탐색, 서버 이동 검증, 카메라가 같은 충돌 영역 사용.
- 새로고침: 게이트웨이가 빌드 후 변경된 자산 이름을 즉시 제공하도록 수정. WAV MIME 및 Range 요청 지원.

## 검증

- `node --test tests/*.test.js` — 전체 단위·통합 테스트.
- `node --test server/*.test.js` — 실제 WebSocket 서버 프로토콜 테스트.
- `node node_modules/vite/bin/vite.js build --configLoader native` — 배포 빌드.
- 메뉴 브라우저 검사: 320px, 390px, 가로 844px에서 버튼 잘림 없음, 화살표 이동, 버튼 사이 드래그, 드래그 후 잘못된 버튼 활성화 없음.
- 안수기도의 서기·앉기 화면, 몸통·머리 충돌, 손 접촉, 원래 카메라 복원, 실제 서버 앉기, 찬송가 무작위 재생과 멈춤, 대화 45초 설정을 검사함.
- 마지막 실행 결과는 `docs/checkpoint-validation-20261116.json`에 저장.

## 저장 및 복원

- GitHub 저장소: https://github.com/Baeksungcil/-temple (`main`, 기존 이력 보존).
- 큰 기존 배경음악과 로컬 실행 상태는 기존 Git 제외 규칙을 유지하고 `backups/Temple-checkpoint-*.zip`에 보관.
- MIDI 원본 및 가사 안내는 `MP3/Hymn/`, 변환기는 `tools/render-hymns.py`, 재생 목록은 `src/hymns.json`에 저장.
- 찬송가 WAV를 재생성하려면 Python 3으로 `python tools/render-hymns.py` 실행. 외부 Python 패키지는 필요하지 않음.
- 신규 체크아웃은 `npm ci`, `npm run server:install` 후 음원 복원/변환, `npm run build` 실행.
- ZIP에는 소스·음원·빌드 결과와 파일별 SHA-256 매니페스트를 포함하며 의존성, 도구 바이너리, 캐시, 이전 백업은 제외.
